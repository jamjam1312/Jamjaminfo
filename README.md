# Jamjam1312 – minimalistisches Portfolio

Die Startseite zeigt absichtlich **nur** eine schwebende, kleine, abgerundete Box mit dem Namen **Jamjam1312**, vier Icon-Links (YouTube, TikTok, GitHub, LOKRO OS) und ganz unten dem kleinen Button **Mehr**. Außen: ausschließlich ein dezenter, animierter Farbglow. Keine sichtbare Kopfzeile, kein Footer, keine zusätzlichen Texte.

**Mehr** öffnet ein zugängliches Dialogfenster mit biografischen Angaben, LOKRO-Netzwerk, Fala Eisdiele und weiteren Links.

## KI und SEO

Das Portfolio enthält Schema.org JSON-LD, `about.json`, `llms.txt` und eine zusätzliche nicht in der Hauptansicht verlinkte HTML-Profilseite unter `ai/`. Diese Dateien sind öffentlich, können von Suchmaschinen gelesen werden, aber Google-/KI-Indexierung ist nicht garantiert.

Da der Betreiber minderjährig ist, enthalten die maschinenlesbaren Metadaten nur den öffentlichen Nutzernamen, keinen bürgerlichen Namen oder exaktes Geburtsdatum. Ältere Git-Commits können weiterhin früher veröffentlichte Angaben enthalten.

Keine Cookies, keine Analyse-Skripte, kein Framework und keine externen Laufzeit-Abhängigkeiten.
