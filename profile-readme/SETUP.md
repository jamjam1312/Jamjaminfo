# GitHub-Profil-README installieren

**Warum dieser Ordner?** GitHub kann ein Profil-README nur aus einem öffentlichen Repository anzeigen, dessen Name exakt dem GitHub-Benutzernamen entspricht. Das Repository `jamjam1312/jamjam1312` existierte beim Erstellen dieser Vorlage noch nicht. Dieser Ordner im Portfolio-Repository ist eine fertig vorbereitete Kopiervorlage, **noch nicht** das aktive GitHub-Profil.

## In wenigen Schritten

1. Auf [GitHub: neues Repository](https://github.com/new) gehen.
2. Repository-Name exakt **`jamjam1312`** wählen.
3. Sichtbarkeit **Public** wählen und **Add a README file** aktivieren.
4. Auf **Create repository** klicken.
5. Im neuen Repository auf `README.md` und auf das Stift-Symbol klicken.
6. Den bisherigen Inhalt durch die vollständige Datei [profile-readme/README.md](./README.md) ersetzen, dann **Commit changes**.
7. Das GitHub-Profil unter **https://github.com/jamjam1312** neu laden.

## Hinweise

- Diese Profilvorlage enthält **keine** Referenz auf das Repository `Jamjaminfo` als besonderes Projekt; sie verlinkt nur die veröffentlichte Website und hebt LOKRO OS hervor.
- GitHub stellt den echten Beitragskalender automatisch unter dem Profil dar. Externe Statistik-Bilder sind ein zusätzliches Element; Zahlen werden **nicht** erfunden.
- Die Statistik- und Skill-Icons laden Bilder von Drittanbietern; diese Dienste können zeitweise ausfallen.
- Persönliche Angaben wie Adresse, Schule, Geburtsdatum oder bürgerlicher Name gehören nicht in die öffentliche README.

## Bild für Google

Im Portfolio wurde vorläufig das **bereits öffentlich sichtbare GitHub-Avatar** als Bildverweis eingebunden. Ein echtes Porträt wurde nicht hochgeladen oder erfunden. Sobald ein ausdrücklich freigegebenes eigenes Bild vorhanden ist, kann es die Avatar-Adresse in `index.html`, `ai/index.html` und `about.json` ersetzen. Weder Google-Bildvorschau noch KI-Ergebnis sind garantiert.

Das eigene Favicon in Google-Suchergebnissen ist bei GitHub-Projektseiten eingeschränkt, weil Google nur ein Favicon pro Hostname berücksichtigt. Eine eigene Domain wäre die saubere Lösung.
